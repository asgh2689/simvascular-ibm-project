# simvascular-ibm-project

## Objective

Can we use the immersed boundary method (IBM) to handle fluid-structure interactions (FSI) in SimVascular? That's what this project is trying to do!

## Motivation

I used SimVascular quite a bit during graduate school, but it was unable to handle complex geometries (such as a patient with an aortic valve). I asked myself, could we fix this problem in SimVascular?

## Project Goals

- Study IBM formulations
- Review existing FSI approaches
- Evaluate compatibility with SimVascular workflows
- Develop prototype implementations

## Current Status

Project planning and literature review phase.

Implementation has not yet begun.
