# simvascular-ibm-project

## Objective

Can we use the immersed boundary method (IBM) to handle fluid-structure interactions (FSI) in SimVascular? That's what this project is trying to do!

## Motivation

During graduate school I used SimVascular quite a bit, but it was unable to handle complex geometries (such as a patient with an aortic valve). I asked myself, could we fix this problem in SimVascular?

## Project Goals

- Develop an understanding of the immersed boundary method
- Review existing FSI approaches
- Evaluate compatibility with SimVascular
- Try to implement IBM into SimVascular (using a plugin?)
